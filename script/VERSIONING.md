# 版本规则

显示版本使用 `主版本.功能版本.修订版本`，例如 `1.9.01`。修订版本至少两位；内部构建号独立递增，不作为用户版本展示。

- 小修改、修复：`--bump patch`（默认），`1.9.01 → 1.9.02`。
- 大功能：`--bump minor`，`1.9.01 → 1.10.00`。
- 重大全面优化迭代：`--bump major`，`1.9.01 → 2.0.00`。
- 发布指定版本：`--version 1.9.01`。
- 重打同一版本：`--no-version-bump`，显示版本和构建号均保持不变。

运行 `bash script/package_app.sh` 构建安装。根据变更范围选择递增级别；不要因修订次数多就自动升级功能版本。构建或安装失败时恢复项目版本。应用正在运行时不覆盖安装。
